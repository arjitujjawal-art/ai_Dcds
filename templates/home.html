Relational Database Model

Schema Structure

Normalized tables (students, subjects, marks, attendance) modeling academic entities with strict primary keys and foreign key constraints.

students (PK: student_id) • marks (FK: student_id, subject_id)
📐

Entity-Relationship Modeling

1:N • Cardinality

Live ER diagram generated directly from SQLite metadata via PRAGMA foreign_key_list, showing one-to-many relationships between students, subjects, and examination marks.

students ||--o{ marks • subjects ||--o{ attendance
⚡

Relational SQL Algebra

Joins • Aggregations

Full support for multi-table INNER/LEFT JOINs, GROUP BY, HAVING thresholds, subqueries, and aggregation functions (AVG, SUM, COUNT, MIN, MAX).

JOIN attendance a ON s.student_id = a.student_id HAVING ...
🛡️

Query Processing & AST Security

sqlglot • Zero Trust

Abstract Syntax Tree parser guarantees that only read-only SELECT queries reach SQLite. Blocks DROP, INSERT, DELETE, multiple statement injection, and restricts access by role.

isinstance(syntax_tree, exp.Select) • Auto LIMIT 50
🔍

Schema Management & Introspection

PRAGMA • Dynamic

Dynamic inspection of table catalogs, column datatypes, nullability, default values, and live row counts without hardcoded schema assumptions.

PRAGMA table_info • PRAGMA foreign_key_list
📜

Audit Logging & Query History
